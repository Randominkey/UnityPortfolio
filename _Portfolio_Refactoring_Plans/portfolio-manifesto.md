# PORTFOLIO MANIFESTO: 5-Year Evolution into Unified Framework

## 1. 비전 (Vision)
"파편화된 5년의 경험을 하나의 완성도 높은 아키텍처로 통합한다."
단순히 예전 프로젝트를 모아놓는 것이 아니라, 최신 소프트웨어 공학 기법(DI, Reactive, SOLID)을 적용한 **통합 프레임워크**를 구축하고, 과거의 프로젝트들을 이 시스템 위의 **모듈**로 재탄생시킨다.

## 2. 핵심 어필 포인트 (Technical Pillars)

### A. 현대적 의존성 관리 (Zenject/DI)
- 시니어의 설계를 깊이 이해하고 응용하는 능력 증명.
- 서비스와 컨텐츠의 완전한 분리를 통한 유지보수성 극대화.

### B. 반응형 상태 제어 (UniRx)
- 명령형(Imperative) 로직에서 선언적(Declarative) 반응형 로직으로의 전환.
- 복잡한 비동기 및 UI 이벤트를 체계적으로 처리.

### C. 확장성 있는 설계 (SOLID & Design Patterns)
- **Command Pattern**: Undo/Redo 시스템의 정석적 구현.
- **Strategy/State Pattern**: 비대해진 조건문을 객체지향적으로 분리.
- **Factory Pattern**: 객체 생성 책임의 분리와 유연한 확장.

### D. 데이터 중심 설계 (Data-Driven)
- ScriptableObject를 활용한 컨텐츠와 로직의 분리.
- 생산성 향상을 위한 커스텀 에디터 툴 제작 경험.

## 3. 리팩토링 로드맵 (Roadmap)

1.  **Phase 1: Master Framework Design**
    - 공통 인터페이스 및 베이스 시스템 정의.
2.  **Phase 2: Archeology & Extraction**
    - 과거 프로젝트 분석 및 핵심 알고리즘 추출.
3.  **Phase 3: Integration & Migration**
    - 추출된 로직을 마스터 프레임워크 규격에 맞춰 이식.
4.  **Phase 4: Polish & Documentation**
    - 코드 주석 정리, 기술 문서화, 성능 최적화.

## 4. 성공 지표 (Success Metrics)
- "과거 프로젝트의 코드를 가져올 때, 프레임워크 코드는 단 한 줄도 수정하지 않아도 되는가?"
- "새로운 게임 모듈을 추가할 때 소요되는 시간이 기존 대비 50% 이상 단축되는가?"
