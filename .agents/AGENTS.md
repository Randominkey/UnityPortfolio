# Project Rules & Guidelines

## 1. 문서 보존 및 아카이빙 규약 (Documentation Persistence)
*   **프로젝트 내 영구 저장**: 사용자가 나중에 확인할 가능성이 있는 유저 매뉴얼, 기술 보고서, 세션 로그, 마일스톤 태스크 보드 및 구조 분석 결과물은 임시 성격을 띠는 에이전트 브레인(`brain`) 폴더 대신, 반드시 프로젝트 워크스페이스 내부의 적절한 폴더(예: `_Portfolio_Refactoring_Plans/` 또는 `_Portfolio_Refactoring_Plans/logs/`)에 누적 저장해야 합니다.
*   **세션 연계**: 다음 세션을 시작할 때 이 문서들을 최우선 검토하여 히스토리를 사용자에게 설명하고 작업을 이어나가야 합니다.
